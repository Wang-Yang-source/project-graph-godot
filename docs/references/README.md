# 参考资料

## 从这里开始

| 需要找什么 | 入口 | 存放规则 |
| --- | --- | --- |
| 论文、研究报告、书章和方法文章 | [论文总索引](papers/README.md) | 23 份 PDF 按 6 个主题统一存入 `papers/`；另列 3 条待获取全文记录 |
| 完整书籍或课程草稿 | [书籍文件索引](books/README.md) | 2 份 PDF 存入 `books/`，与论文分开 |
| 结构化思维的书目、证据边界、框架和案例 | [专题入口](structured-thinking/README.md) | `structured-thinking/` 保存研究整理与应用材料，通过相对链接引用原文 |

## 目录结构

```text
references/
├── README.md                 # 总入口
├── papers/
│   ├── README.md             # 全部论文与研究材料索引
│   ├── sources.json          # 来源、版本、归档与失败记录
│   ├── representation/      # 表征、概念图与图可视化（4）
│   ├── learning/            # 学习、自我解释与学习效果（3）
│   ├── argumentation/       # 批判思维与论证制图（3）
│   ├── judgment/            # 判断偏差、去偏差与预测（4）
│   ├── systems/             # 问题结构、因果与系统干预（4）
│   └── tools/               # 笔记、知识工作工具与本地优先（5）
├── books/                   # 完整书籍与课程草稿（2）
└── structured-thinking/     # 专题书目、方法蓝图、案例和原生图
```

每份原文只存一处。主题用于查找，不表示所有材料具有相同证据强度；方法定义、实验、综述与元分析的区别见文献索引。PDF 内容、原文件名及版权声明保留，已有专题和软件设计文档的原文链接随迁移更新。
