- PDF 原文件保持内容与文件名；书稿文件名中的年份仍保留，实际版本年份在书籍索引说明。
- `sources.json` 是全库论文来源目录，`file` 相对本目录；失败记录的 `file` 为 `null`，不提供假本地链接。保留原下载日期、字节数、SHA-256、版本、重定向和失败尝试。
- `structured-thinking/sources.json` 保留该专题的来源与阅读记录，其文件路径已更新；专题 P 编号与本总索引一致。
- 新资料先判断主题和文献类型，再检查是否已收录；沿用“年份-作者或工具-主题.pdf”，补充索引与来源记录。跨主题资料选一个主要存放位置。
- 本次为目录与引用整理，未新增全文研究结论。既有阅读范围保留；新增 H01–H06 作者资料仅据首页核对，未逐篇全文审读。
