# 加载完成不等待整图动画

取消整份文档按 2.2 秒时间轴排队显示和至少 2.4 秒完成的限制。已完成的批次立即开始短淡入动画，仍使用现有 WorkerThreadPool、分帧构建和历史快照，未引入依赖。

Godot MCP 脚本读写和编辑器脚本执行测试。`loading_responsiveness_smoke.gd` 在旧实现中仅耗时断言失败（2570.6ms），修改后通过（688.952ms）；覆盖 239 个对象、跨对象引用、保存位置、撤销、关闭加载标签、连续文件取消和读取失败后的恢复。

真实 1028 对象文件验证：2472.024ms 完成、179.575ms 首批可见、文件哈希和引用保持正确。该数据包含高 DPI 修复；不能把小夹具提升比例外推到所有大项目。

现有 `progressive_loading_smoke.gd` 的组预览部分有三类断言失败：预览出现时机、内部细节隐藏、最终嵌套预览数量。恢复旧加载器重测仍出现相同失败，属于当前工作区已有的组预览逻辑与测试条件差异，本修改未改变或跳过原测试。

手动验证：打开大项目，完成的节点应立即出现，完成后可编辑；加载期间关闭标签，再打开另一文件应正常；撤销、连线端点和节点位置应保留。失败时重点观察长时间空白、动画结束后仍禁止编辑、取消后留下对象或连线失去端点。用户实际桌面会话和发行包验证尚未执行。
