# 连线生成动画

实际修改：拖动创建成功的新连线，通过 Godot 原生 Tween 在 0.32 秒内用 cubic ease-out 从起点沿曲线弧长显示到终点，箭头随后淡入，标签在经过中段时渐显。仍由原有 Line2D、Polygon2D、Caption 节点显示；碰撞和完整逻辑曲线始终存在，动画进度不进入序列化或历史。重复连接不重播，普通构建及加载不播放，删除连线时销毁 Tween。没有新增依赖。

使用 Godot MCP 脚本读取、创建、修改、编辑器脚本执行工具。

已运行 edge_creation_animation_smoke、navigation_cache_smoke、edge_caption_smoke、smooth_connections_smoke、chain_contact_smoke，均通过。覆盖真实连线工具入口、显示进度、碰撞与持久化不变、重复连接、动画中缩放和移动端点、精确终态以及删除清理。

尚未执行的手动验证：启动修改后的项目，从一个节点右键拖动到另一个节点并松开（或使用左键连线模式）；新线应从起点平滑延伸，箭头和标签逐渐显示。创建时缩放或拖动端点，结束后曲线应贴合两个节点。重复连接不应重复闪烁；打开现有项目不应整图播放动画。若失败，重点检查完成后缺少末段、箭头透明、缩放后断线或删除时报错。
