# 拖拽连线预览动画

实际修改：动画发生在拖拽连线的过程中。超过点击阈值后，临时 Line2D 通过 Godot 原生 Tween 在 0.2 秒内渐进伸出，曲线末端跟随鼠标；目标节点的真实连接点单独高亮。采用原生 Curve2D 烘焙采样显示部分曲线。松开后正式连线立即完整显示，取消、空白释放及关闭舞台清理临时 Tween。此前连接完成后的播放已移除。预览不进入序列化或历史，没有新增依赖。

使用 Godot MCP 脚本读取、创建、修改、编辑器脚本执行工具。

已运行 edge_creation_animation_smoke、navigation_cache_smoke、edge_caption_smoke、smooth_connections_smoke，均通过。覆盖点击阈值、连接前的渐进预览、鼠标跟随、目标高亮、取消清理、文档不变、松开后的完整连线、单步撤销及空白释放。

尚未执行的手动验证：启动修改后的项目，从一个节点右键拖动（或使用左键连线模式），先停在空白处，再移到目标节点。按住期间应看到从起点伸出的临时曲线，其末端随鼠标移动；松开后直接成为完整连线。Esc、空白释放或关闭舞台后不应残留预览。若失败，重点检查按住时没有动画、预览提前成为最终连接或取消后残留。
