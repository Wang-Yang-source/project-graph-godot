# 分组边界内的连接范围

Stage.can_connect_entities 统一验证端点必须属于当前舞台且处于同一直接容器。正式创建及拖拽目标高亮共用该规则，阻止内部节点连接外部节点、其他分组成员及自身分组框。分组框之间可在其共同上层连接。拒绝的手势不修改文档，不增加历史；现有文件的读取没有删除旧数据。

复用已有容器引用及 Godot 类型检查，无新增依赖。使用 Godot MCP 脚本读取、创建、修改、编辑器脚本执行工具。

container_connection_scope_smoke 修改前失败，修改后通过，覆盖内外双向拒绝、内部正常连接、分组间连接、无目标高亮及无历史副作用。edge_creation_animation_smoke、slice_ungroup_smoke 通过。

尚未执行的手动验证：从分组内节点分别拖向同组节点、组外节点、其他分组成员及自身标题。只有同组节点应成为可连接目标；组外释放不应产生连线。分组标题之间仍应允许连接。若失败，重点检查目标高亮与实际创建是否一致，以及无效操作是否产生撤销记录。
