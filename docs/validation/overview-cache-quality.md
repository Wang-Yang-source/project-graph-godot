# 大分组预览清晰度

修复固定 512 像素缓存被放大后出现粗边框、折线锯齿和微小标题的问题。复用 Godot 原生 mipmaps 和 Panel/Line2D，按分组物理屏幕尺寸的两倍选择 512–4096 像素缓存，按二次幂升级；同一预览缩回时保留已生成的清晰纹理。边框、连线按生成时约 1.25 物理像素取宽，曲线复用现有连接函数提高采样；分组标题以 14 物理像素为期望值，仍受原始宽度与标题区域限制。没有新增依赖。

所有 Godot 文件均使用 Godot MCP 的脚本读取/修改/创建与编辑器脚本执行工具。GPU 树层级、普通文本、分组几何回归通过；新增大尺寸升级及缩回缓存复用检查。只读加载 tutorial-shortcut-keys-3.1.prg，在三档缩放生成并检查截图。普通文本的原文、包含关系和保存内容保持不变。

尚待用户手动验证：启动新版，打开快捷键教程，在截图所示视角缩放、平移。应观察到更细且连续的边框、平滑彩色曲线和更清楚的分组标题。失败时重点检查放大后粗线/方块像素、缩回时缓存反复生成、标题覆盖相邻内容。4096 像素上限以上的超大预览、Windows release 和长时间连续编辑未验证。
