# 折叠分组的交互移动锁

折叠分组显示标题预览时，隐藏的内部 Entity 不再接受独立鼠标拖动、选中对象的键盘移动或 Alt 层级移动，也不能单独启动惯性。正在进行的内部鼠标拖动会无惯性结束，关闭输入/物理回调，并沿现有事务提交一次；展开后可再次独立拖动。外组驱动的固定偏移同步、撤销/重做和加载仍可更新持久坐标。本切片不改变显式自动布局命令。

复用现有 Godot RigidBody2D、输入入口和 History 事务接口；无需新库或额外状态系统。Godot 源码与定向测试通过 MCP script 读写、资源 reload 和异步 headless child 处理。未修改物理频率、CCD 或轮廓精度。

定向自动回归：`res://tests/hidden_group_movement_lock_smoke.gd`。覆盖隐藏输入/throw、callbacks、键盘/多选/Alt roots、展开、拖动中折叠、单次事务/撤销与外组固定偏移同步。

手动验证（尚待用户执行）：

1. 打开 `tutorial-shortcut-keys-3.1.prg`，放大后选中一个分组内部元素，再缩小到只显示分组标题。尝试拖动、选中移动快捷键或 Alt 拖动；内部元素应保持相对位置。混合选择内部元素和外部可见元素时，仅外部元素独立移动。
2. 拖动内部元素时保持鼠标按下并缩小视图至标题预览，随后松开。内部独立拖动应立即结束，不应继续漂移；撤销一次应恢复整个未完成拖动的起始位置，不应新增第二个空操作。
3. 拖动折叠分组标题并释放，再放大展开。全部内部元素应随外组整体平移，展开后能重新单独拖动；撤销/重做应保持有效。

失败时重点检查：隐藏成员仍在跟鼠标、仍有惯性、Alt 或多选绕过锁、折叠后 release 又提交一次，或展开/撤销时发生旧位置回跳。
