# 加载后的容器标题样式

修复加载时容器状态未参与外观缓存判断的问题。普通文本框转成容器后，标题现在切换到透明、无边框样式，容器轮廓保留。复用 Godot 的 Label/StyleBox 和现有样式缓存，无新增依赖。

通过 Godot MCP 脚本读写、编辑器脚本执行测试；未直接读写场景文件。

`loading_title_style_smoke.gd` 修改前失败，修改后通过，覆盖深浅主题、标题内容和容器轮廓。

手动验证：打开包含“键盘快捷键”等容器的项目，放大到标题可读；标题应只有文字，外围容器保留轮廓。切换深浅主题并重新打开文件。失败时重点观察标题是否仍有贯穿容器的长条边框。尚未执行用户实际桌面会话下的手动验证。
