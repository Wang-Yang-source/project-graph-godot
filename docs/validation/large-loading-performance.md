# 大文档加载性能

## 实际改动

- `src/project_loader.gd`：超过 256 个对象时，完成的批次直接显示，省去逐对象 Tween、连线显示材质及最后一批动画等待；小文档保留原有动画。
- 初始历史快照继续使用每帧 12 ms 的时间预算，移除每帧最多 64 个对象的额外限制。
- `tests/large_loading_smoke.gd`：覆盖分批显示、完整对象和引用、初始干净状态、源文件不变，以及编辑后的撤销恢复。

复用现有 Godot 时间预算、节点显示与历史序列化能力；不新增依赖，也不替换通用库。Godot 文件通过 MCP 脚本读取、修改、创建和编辑器脚本执行类别处理。

## 已执行验证

用户授权后，通过 Godot MCP 启动隔离进程，使用独立临时用户数据目录，不保存用户文档。

- `large_loading_smoke.gd`：通过；恢复旧加载器时，新测试在大文档直接显示断言处失败。
- `loading_responsiveness_smoke.gd`：通过，覆盖取消、关闭加载页、后续加载、错误恢复、引用及历史。
- `text_edit_geometry_smoke.gd`、`loading_title_style_smoke.gd`：通过。
- 最终脚本解析检查及提交范围的 `git diff --check`：通过。

Godot 4.8.dev6、Linux X11 环境，1001 个对象文档，相同桌面条件下各测量两次：

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 加载耗时 | 2241.878 / 2258.999 ms | 1994.975 / 1941.528 ms |
| 平均加载耗时 | 2250.439 ms | 1968.252 ms |
| 首批可见时间 | 185.785 / 193.507 ms | 165.793 / 160.335 ms |
| 帧耗时 p95 | 31.090 / 30.865 ms | 31.102 / 35.874 ms |

平均加载耗时下降约 12.5%。测量仅包含文档加载，不包含应用启动；不能保证其他桌面负载下同样耗时，帧耗时仍有波动。源文件哈希、对象数量、引用和完成状态检查均通过。
