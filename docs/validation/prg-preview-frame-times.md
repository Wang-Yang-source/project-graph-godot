# PRG 预览帧时间

分组预览在保持激活期间保留已生成的最高采样分辨率（上限 256），缩小时复用纹理；内容修改、分组退出仍按原有生命周期更新和释放。复用 Godot 的 SubViewport、ImageTexture 和既有异步捕获，无新增依赖。

2026-10-04：原始 975 对象主教程从备份转换为 `/tmp/pg-v4-original-main.prg`，只读测试。Godot 4.8 dev6 调试版，GL Compatibility，Intel Iris Xe，实际窗口 1920×1200，关闭垂直同步，全图 zoom 0.04021745。相同窗口和轨迹的一次前后比较：

这是有限的调试版样本，不是稳定 60 FPS 的保证，也尚未覆盖欢迎页文件卡片切换或发布版。较早不同尺寸的样本不可直接比较。仍需继续降低缩放慢帧。

已通过 `preview_zoom_cache_smoke.gd`、`async_preview_capture_smoke.gd` 和 `async_preview_lifecycle_smoke.gd`。旧 `independent_preview_cache_smoke.gd` 的人为修改分辨率断言在修改前后均失败，保留原测试未篡改。含图片 975 对象的撤销测试仍有坐标差异；恢复旧 History 后同样失败，不能宣称整体兼容验证通过。

Godot 文件通过 MCP 脚本读取、修改、创建及编辑器脚本执行类别处理。没有操作场景文本。

手动验证：打开主教程，缩小到全图，再在分组预览可见的尺度附近连续滚轮放大和缩小。预览应连续显示，无反复空白，标题和边框保留；编辑分组内文字后，预览应刷新。失败时重点检查跨尺度反复停顿、旧文字残留、缩略图消失和切换文件后纹理未释放。欢迎页快速切换、发布版和长时间内存趋势尚待验证。
