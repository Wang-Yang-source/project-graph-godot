# 分组标题覆盖外框

标题 Label 与 ContainerPanel 共用左上角，工作区现有标题背景以 0.92 不透明度绘制，覆盖了先绘制的上边框及上方圆角。通过原生 StyleBox 的负 expand_margin，将标题背景的上、左、右边各内缩外框宽度；文字内边距、位置、碰撞和分组尺寸不变。不增加节点、绘制层或纹理，不引入依赖。保留工作区已有标题背景和其他界面改动；提交仅约束标题背景的绘制范围。

使用 Godot MCP 的脚本读取、修改、创建和编辑器脚本执行工具。通过 PackedScene 状态 API 检查节点配置，未读取场景文本，也未操作编辑器界面。

真实教程“选中连线后可以观察到连线的端点位置”分组已复现并对比截图。新增 `group_header_border_smoke.gd` 图形测试：修复前顶部亮度 0.20、底部 0.38，修复后两者均约 0.38；修复前失败、修复后通过。检查标题边距和几何不变。尚未由用户执行手动步骤，尚未测其他平台和 release；没有运行外部格式工具。

手动验证：重新打开教程，定位该分组，放大查看上边、上方两个圆角和下边，再缩小并编辑标题。预期外框亮度一致、标题背景仍可读，编辑时不跳动。失败时重点检查顶边仍被压暗、标题背景伸出圆角、文字或分组尺寸改变。
