# 完整文档与活动视图

完整 GraphDocument 现在保留所有记录。Stage 保存与历史捕获只合并活动视图的变化；没有视图的记录不再被当作删除。视图回收不改正文，历史先恢复完整模型，再同步活动记录与必要依赖。选择未显示记录会创建视图。模型提供完整计数、文字查询、包含子树移动和级联删除（包含主题引用清理、端点边及集合成员）。

PRG 图片块以内容 ID 保持延迟句柄，快照适配不再为取得图片身份读取字节。实际显示和保存仍读取并校验块；写失败不会替换原文件。加载器在替换舞台前验证完整原生模型。未能合并活动视图时保存明确失败，不能用残缺视图覆盖文件。

复用 Godot Dictionary、PackedArray、WorkerThreadPool 和既有 Variant/块存储；没有引入通用存储、索引或新依赖。记录顺序以文档为准，加载优先级不再改变持久对象次序。
