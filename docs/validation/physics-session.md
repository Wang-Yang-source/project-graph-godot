# 局部原生物理会话

静止的舞台实体保留原生碰撞体但冻结运动，避免打开文件、编辑文字和撤销时把原有重叠节点推开。拖拽或投掷开始后，由 PhysicsSession 在物理回调中复用 Godot 的 PhysicsDirectSpaceState2D 原生宽相查询，激活扫掠范围内的邻居及接触链。包含关系的碰撞例外仍保留。稳定后或历史提交、取消、重新加载时，参与者停止运动并释放会话。

优先复用引擎现成空间查询，不引入或自行实现 R-tree、通用碰撞检测或第三方物理库。当前仍保留所有轻量物理实例；未显示记录的物理实例按需构造要在呈现迁移中继续接入，不能宣称超大图局部物理已经完成。
