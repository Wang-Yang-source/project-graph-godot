# 舞台原生像素渲染

UI 200% 时，旧舞台仅渲染 1152×567，再拉伸到 2304×1134。现在通过原生 SubViewport 的 size_2d_override 保留逻辑坐标，SubViewportContainer 调整尺寸与显示缩放，在实际显示像素上绘制文字与线条。相机缩放不重建缓冲区。网格使用相同的渲染比例，保留原来的世界间距和界面线宽。

复用 Godot 原生视口、输入转发和 ShaderMaterial，无新增依赖。使用 Godot MCP 脚本读写、原生资源读取、编辑器脚本运行验证；场景文件未直接改写。

验证：hidpi_stage_smoke 修改前失败，修改后通过；覆盖 200% 和 125% 界面比例、世界位置、相机缩放不重建缓冲区、从根窗口发出的鼠标点击命中、网格比例及关闭标签。save_dialog_theme_smoke、welcome_stage_smoke、canvas_sampling_smoke 通过。实际窗口截图已检查。提高分辨率增加像素渲染量，收益和帧率取决于显卡及屏幕大小。

手动验证：重新启动修改后的程序，打开大项目，在设置中切换 125%/200%，连续缩放舞台；中文标题、斜线应清晰，网格应跟随节点的位置，点击文字应命中，关闭标签和保存对话框正常。失败时检查是否仍运行旧进程、文字边缘是否发虚、鼠标是否偏移或网格间距是否改变。尚未执行用户实际桌面会话的手动验证和发行包验证。
