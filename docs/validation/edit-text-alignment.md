# 编辑文字位置

复用 Godot Label.get_character_bounds 获取实际文字起点，并补偿 TextEdit 行框的额外行高，避免中心对齐、非对称边距导致进入编辑时跳动。使用 Godot MCP 脚本读取、修改和编辑器脚本执行工具；没有新增依赖。

已运行 edit_text_alignment_smoke、edge_caption_smoke、caption_selection_style_smoke，均通过。像素回归覆盖普通节点与连线标签、中英文混排、1 倍与 2 倍缩放，以及取消编辑。原先节点向下移动 1/2 像素，标签移动 (-5,4)/(-10,8) 像素；修复后均为 0 像素。

手动验证（尚未执行）：启动修改后的项目，分别双击普通节点和带文字的连线，在 1 倍、2 倍缩放下观察文字；确认和取消编辑后，原文字应保持位置。若仍跳动，重点检查进入编辑的第一帧、字体大小、中文输入法预编辑以及多行文字。
