# 连线标签的编辑选区

选区此前继承了不透明的深色界面选中背景，并使用独立的选中文字颜色，黄色标签上显示成深色块。现在复用 TextEdit 原生选区，将选区颜色设为标签前景色的 18% 透明覆盖，同时选中文字保持原来的对比色。编辑器透明背景与标签圆角底色保持不变；无新增依赖。

使用 Godot MCP 脚本读写与编辑器脚本运行测试。caption_selection_style_smoke 修改前失败，修改后通过；覆盖深浅主题、明暗标签、全选、取消和提交。已查看修改后窗口截图。

手动验证：双击黄色连线标签，选中“3次”；应显示轻微高亮，黄色底色仍可见，文字清楚。按 Esc 应恢复原文，重新编辑并确认应显示新文字。失败时检查是否仍出现深色块、选中文字失去对比或取消后草稿被保存。用户实际桌面与发行包验收尚未执行。
