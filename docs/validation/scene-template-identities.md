# 场景模板对象 ID 修复

实际缺陷：text_node.res 和 line_edge.res 在生成二进制 PackedScene 时保存了实例的随机 ID，之后每次实例化都会得到同一个 ID。v4 唯一身份校验正确拒绝了包含多个新文本节点的保存。

通过 Godot MCP PackedScene 实例化/重新打包与 ResourceSaver 移除模板里的实例 ID；StageObject 在进入节点树时为仍为空的 ID 生成唯一值，保留恢复时已经设置的持久 ID。复用已有 NanoID，不新增依赖，不读取场景文本。使用工具类别：脚本读取/修改、编辑器脚本执行、原生场景打包与资源保存。

验证：撤下文档模型接入后，native_dirty_smoke 与 PRG v4 存储回归均通过，说明此修复独立有效。文档模型接入后这些回归也通过，975 对象主教程的撤销保留 975 个实例。二进制模板各缩小 45 字节。

用户手动验证：新建两个文字节点并连接，保存为 .prg 后关闭重开。三个对象及连线应完整保留，文件保存后干净；失败时检查对象 ID 为空或重复的错误及恢复后引用断开。GUI 手动验证尚未执行。
