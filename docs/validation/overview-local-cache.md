# 概览局部缓存

概览复用现有 Godot 节点、geometry 通知、Rect2、缩略图捕获及 shape/topology revision；没有新增依赖。拓扑变化重建成员索引，位置变化只读取对应实体和受影响祖先的边界。缩略图内容比较分组内的相对几何；全组等量平移复用图像并更新位置，成员相对移动、文字、字体、样式或分辨率变化仍使内容失效。

回归入口为 `tests/overview_local_translation_smoke.gd`，覆盖整体平移、无关分组保留、相对位移、文字、字号和重新归组。脚本解析及空白检查由 Godot MCP 执行。性能结果另见指定快捷键文档专项记录；本页不把逻辑测试通过当作达到 60 FPS 的证据。

手动打开 `tutorial-shortcut-keys-3.1.prg`，缩小至分组预览，拖动一个分组并连续缩放；预览应跟随，成员、边框、箭头、文字和点击命中保持一致。再放大移动一个子节点、修改文字及字号、移出和移入分组，缩小检查预览更新，并撤销/重做。失败时重点检查缓存未失效、旧图像位置、祖先边界、预览成员索引及历史恢复；这些视觉和实际拖动检查尚需用户执行。

相关旧测试 `group_miniature_composition_smoke.gd` 仍要求原始根标题保留且禁止居中总览标题，与本次工作开始前的工作区显示设计不一致。旧 `text_detail_smoke.gd` 的相机未隔离导航缩放下限，原源码与候选均出现相同失败；不得计作本次性能回归通过。
