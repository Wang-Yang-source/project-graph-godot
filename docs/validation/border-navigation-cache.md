# 边框导航更新缓存

复用 Godot 原生 Rect2、Transform2D 和既有每倍频程 16 档边框采样。相机纯平移时，边框不再逐帧进入完整的祖先可见性、样式和圆角更新；仅在重新进入视野、跨越采样档位或几何、主题、控件尺寸变化时唤醒。节点、填充、抗锯齿纹理、世界坐标和点击范围沿用原实现，无新增依赖。

Godot 项目文件通过 MCP 脚本读取和修改；测试通过 MCP 编辑器脚本启动独立进程。用户已授权性能测量和回归验证。

`minimum_screen_border_smoke.gd` 通过，覆盖缩小边框像素覆盖、分数相机位置、同档位几何复用、祖先隐藏/恢复、文字 mipmap，以及纯平移不唤醒、缩放档位变化唤醒、离开/进入视野和几何/主题缓存失效。

“教程操作.prg”只读对照：1920×1200，UI 200%，Intel Iris Xe，Godot 4.8.dev6，X11，取消垂直同步，完整图视野。预览缓存优化已启用时，仅增加边框调度缓存，平移从约 87 提升到 100 FPS，缩放从约 63 提升到 72 FPS。此为开发运行实测，后台仍有其他编辑器和应用；不保证所有视野和平台的帧率。

人工验证（待执行）：打开教程操作，保持 UI 200%，缩小至完整图，然后持续平移、缩放并移回刚才离开屏幕的节点；边框与圆角应完整，文字和填充不变。切换主题、调整窗口大小并编辑节点后，边框应及时更新。若有旧宽度、缺边或新进入视野的边框未更新，重点检查进入视野及样式/尺寸变化是否唤醒边框。其他 GPU、旋转与不均匀缩放节点尚需人工复核。
