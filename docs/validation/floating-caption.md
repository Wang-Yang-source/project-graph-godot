# 浮动连线注释

连线文字改用背景自适应的中性色，默认不再显示彩色胶囊或边框。缩小两侧与上下留白，通过与舞台/容器填充同色的原生 Label 背景遮住文字下方线段，形成左右空隙。悬停和编辑时使用轻微圆角色调反馈，不改变文本布局。保留原生 TextEdit、选区轻高亮、IME、撤销及碰撞矩形，无新增依赖。

使用 Godot MCP 脚本读取、创建、修改和编辑器脚本执行工具。floating_caption_smoke 原样式 8 项断言失败，修改后通过，并检查浅/深主题、紧凑尺寸、悬停几何稳定及容器背景混合。edit_text_alignment_smoke、caption_selection_style_smoke、edge_caption_smoke 通过；已检查真实渲染截图。

尚未执行的手动验证：打开带有“说明”连线的项目，文字应像浮动注释，两侧线条留白；切换主题、修改容器底色后仍应清楚。悬停、双击编辑、确认与取消，再缩放；不应跳字、出现深色选区块或旧的大胶囊。若失败，重点检查容器背景接缝、编辑首帧和缩小后的文字。
