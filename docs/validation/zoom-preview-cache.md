# 缩放预览缓存

缩放跨过预览阈值或纹理分辨率档位时，原先会销毁全部分组缩略图，重新实例化、绘制并同步读取 GPU 图片。现改为逐分组检查内容：只重建变化的分组；文档编辑、内部边框组成变化仍使对应缓存失效。沿用 Godot SubViewport、Sprite2D、ImageTexture 和既有预览树，无新依赖。

Godot MCP 脚本读写、创建和编辑器脚本执行完成实现及验证，没有读取场景文本。工作区原有界面修改保留，提交仅含独立缓存修复。

固定 975 对象教程快照，Godot 4.8 dev6 / Intel Iris Xe / Vulkan Mobile / 1920×1200 / UI 200% / VSync 关闭。3 秒连续缩放，目标倍率按 ±25% 正弦变化：

| 初始倍率 | FPS 前/后 | 最差帧 ms 前/后 | P95 ms 前/后 |
| --- | --- | --- | --- |
| 0.08 | 154 / 213 | 319 / 78 | 6.06 / 6.16 |
| 0.15 | 144 / 244 | 557 / 138 | 4.49 / 4.66 |
| 0.30 | 234 / 257 | 204 / 203 | 4.79 / 4.83 |

主要收益是减少少数严重停顿；P95 没有改善，0.30 倍最差帧仍有约 200 ms。数据来自独立调试进程，尚未测 release。复用了现有导航基准；诊断临时脚本采集 P99 和最差帧。

`independent_preview_cache_smoke.gd` 图形测试通过：一个分组提高分辨率不会重建另一个分组，重复刷新保留图片，文档变化仍更新缓存。真实教程 `tutorial_navigation_cache_smoke.gd` 通过，覆盖缩放、平移、几何缓存与原始文档不变。

手动验证尚待用户执行：打开教程，从全图持续放大到节点可读，再缩回；预期缩略图、标题和连线连续更新，跨阈值时停顿减少。编辑组内文字再缩小，应出现新文字。失败时检查缩略图丢失、旧内容残留、边框消失或分组切换时闪白。release 性能和其他平台尚未验证。
