# 缩放圆角纹理预算

极小倍率下，分组保持屏幕圆角需要很大的世界坐标半径。原 SVG 按固定四倍栅格化会生成数千像素纹理；多组跨倍率重建造成秒级停顿。现在 mipmap 画布纹理的单边栅格化尺寸上限为 512，普通节点仍使用四倍采样，ImageTexture 的逻辑尺寸、九宫格切边和源样式半径保持原值。缓存达到 256 条时仅移除最早一条，避免全部清空。

复用 Godot Image SVG 栅格化、mipmap、ImageTexture.set_size_override 和 Dictionary；不引入依赖或自行实现绘制器。Godot 脚本及测试通过 MCP 读取、修改、创建与执行，没有操作场景文本。

corner_texture_budget 先失败后通过；continuous_corners 与实际像素 canvas_sampling 通过，正常最大倍率的圆角保留 475 个半透明边缘像素。1028 对象教程，X11、Compatibility、Iris Xe，既有 zoom_frame_benchmark 原生手势路径：修改前广范围冷阶段最长 1629.5 ms，热阶段最长 1737.0 ms；修改后分别 281.5 ms、316.4 ms。广范围冷阶段 p95 从 1629.5 ms 降至 119.5 ms，热阶段从 201.5 ms 降至 61.2 ms。仍有预览切换慢帧，不宣称稳定 120 FPS。所有对象位置、布局版本及源文件哈希检查通过。指标取同一当前工作区的前后测试，未使用并发测试轮的数据。
