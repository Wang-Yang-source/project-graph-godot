# 分组缩略图几何缓存

实际改动：真实分组不再只用少数标题重建内部结构。使用 Godot 原生 Panel、Line2D、Polygon2D 和独立 SubViewport，按原始世界坐标缓存全部文本节点外形、填色及连线；最长边 512 像素，显示矩形保持原分组比例。生成 mipmaps 并采用预乘 alpha，防止缩小时细线断裂、透明边缘变黑。渲染后释放临时视口与节点。标题仍按下一层显示，避让只比较文字范围；平移、缩放复用纹理，文档或布局修改时刷新。普通文本分支不增加分组框。

复用评估：Godot 原生离屏视口、ImageTexture/mipmaps、现有 Corners 样式来源和 LineEdge 连接几何满足需求，无需引入社区渲染库或新依赖。没有直接调用底层绘制接口，没有修改场景、持久化关系或物理状态。

MCP 工具类别：脚本读取、创建/修改和编辑器脚本执行。所有 Godot 文件操作、测试启动与 Git 暂存均通过 Godot MCP 完成。

已授权并执行：五项 GPU 回归（overview_tree_layers、plain_text_overview、overview_group_geometry、overview_document_appearance、tutorial_navigation_cache）通过。新增回归覆盖平面容器内的树层级、全角数字原文、几何缓存复用、恢复拾取/文字，以及仅文字范围的避让。独立提交版本也通过四项受影响视觉回归。

同条件导航基准：Godot 4.8 dev6、Mobile/Vulkan、Intel Iris Xe、1920×1200、VSync 关闭；教程只读载入，604 节点加 373 连线，全图适配 zoom=0.03395；预热后每阶段采样 3 秒。基准属于本机 debug 运行，不是 Windows release 结果。
