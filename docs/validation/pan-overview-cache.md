# 画布视角平移缓存

实际改动：将总览的世界布局/标题呈现与视口可见性检查分开。平移不改变缩放、对象几何或文档状态时，复用预览矩形和可读性，只更新屏幕内外显示、标题避让及预览连线可见性；首次进入视口的预览仍初始化呈现。缩放、主题、文档和布局变更继续走完整刷新。

复用 Godot 的 Rect2 相交、节点可见性和既有缓存，不引入依赖。Godot 文件只通过 MCP 脚本读取、创建、修改及编辑器脚本执行类别处理。

## 已执行验证

用户授权的隔离进程，独立临时用户数据目录，源文档不保存。

- `pan_overview_cache_smoke.gd`：旧实现失败，修复后通过；检查平移复用呈现、成员稳定、移出屏幕隐藏及返回恢复、源文件哈希不变。提交版本及保留已有改动的工作区版本均通过。
- `tutorial_navigation_cache_smoke.gd`：通过，覆盖多级缩放、世界几何缓存、改名和主题变化。
- `loading_responsiveness_smoke.gd`：通过。
- Godot 原生脚本解析、提交范围空白检查：通过。

配对测量使用现有 `tutorial_navigation_benchmark.gd` 的临时副本，仅关闭物理避让以稳定图形；临时副本测试后删除。981 对象 `tutorial-main-3.1.prg`，1920×1200 窗口、Godot 4.8.dev6、Intel Iris Xe、Mobile Vulkan、X11、Mailbox，各阶段三秒：

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 静止 FPS | 147.25 | 145.58 |
| 平移 FPS | 97.40 | 144.94 |
| 平移帧耗时 p95 | 12.180 ms | 6.996 ms |

这是一次同条件配对结果，并非所有文档和桌面负载的保证。未改变画质或缩放规则。连续缩放仍有较高帧耗时，本修复针对纯平移。

## 用户手动验证（尚未执行）
