# 节点引力、斥力与弹性接触

复用 Godot RigidBody2D 的速度积分、RectangleShape2D/PhysicsShapeQueryParameters2D 邻域查询，以及已有事务历史；不引入第三方依赖，不使用位置 Tween 与物理争夺坐标。

实际改动：

- 磁性斥力采用软化的距离平方反比衰减，接触处有限、16 世界单位以外为零，维持原有轻柔加速度。
- 已连接分量的引力保留安全静止距离，远处按距离平方反比衰减，避免持续把整个图拉成一团。局部拖动不启动全图吸引。
- 接触由非线性阻尼弹簧逐步改变速度，频率 12、阻尼比 0.85；隐式阻尼与六个速度子步提供稳定响应，接触结束后渐进减速。
- 深度重叠允许邻居让出必要空间和有限缓冲，不再被固定 16 单位位移限额卡住。
- 同一容器内，附近连线标签可以通过其端点避让，即使端点不在最小鼠标查询区域内。跨容器连线不扩大内部节点的移动范围。

工具类别：Godot MCP 脚本读取、创建、修改、编辑器脚本执行。未修改场景结构或第三方目录。

验证：overlap_clearance_smoke 原版本无法清除深度重叠，也无法使拖动节点避让端点位于查询范围外的标签；修改后通过。spring_contact_smoke 覆盖 30/60/120 Hz 的有限弹性响应和浅接触弱响应。inverse_square_forces_smoke 覆盖远场吸引减弱、斥力单调衰减和零距离有限值。另通过 node_repulsion_smoke、local_drag_physics_smoke、linked_attraction_smoke、physics_scope_smoke、property_local_physics_smoke、visual_edit_physics_smoke，覆盖局部作用域、容器成员、停止运动及撤销/重做。旧的固定位移限额断言改为“消除重叠且仅移动必要让位距离加局部缓冲”。

尚未执行的手动验证：启动修改后的项目并开启物理，缓慢及快速拖动节点接触另一节点和同容器内的连线标签，再松手。应看到邻居弹性让位、逐渐减速并分开，鼠标控制的节点保持跟手，远处节点保持原位。撤销与重做应恢复完整布局。若失败，重点检查接触后的反复抖动、突然跳位、持续重叠以及远处或其他容器成员被移动。输入法预编辑期间的避让与极端密集多层图仍需人工检查。
