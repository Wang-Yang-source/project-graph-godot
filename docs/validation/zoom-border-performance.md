# 缩放边框性能

缩放时容器圆角重复生成 SVG 纹理并替换 StyleBox，造成主题失效和帧耗时尖峰。离屏文本、容器边框也持续重新烘焙折线。现在复用现有圆角曲线和 Godot 的 Line2D、Polygon2D：低倍率时使用原生轮廓与填充，保持内容边距，仅在进入/退出此显示模式时替换样式；离屏更新延迟到重新进入视口。保持节点世界几何、物理碰撞、字体缓存与原有屏幕圆角尺度，无新增依赖。

通过 Godot MCP 读写脚本、原生场景实例化和编辑器脚本运行测试，未直接读写场景文件。复用了引擎提供的抗锯齿多边形、矩阵和控件样式能力，无需外部库。

同一 1028 对象文件，X11、Compatibility、关闭垂直同步，真实放大手势往返缩放；单位 ms：

| 阶段 | 修改前 P95 | 修改后 P95 | 修改前最大帧 | 修改后最大帧 |
| --- | ---: | ---: | ---: | ---: |
| 局部缩放 | 25.250 | 7.641 | 34.014 | 31.829 |
| 大范围首次 | 113.953 | 20.312 | 328.965 | 60.703 |
| 大范围重复 | 100.664 | 20.073 | 287.464 | 42.179 |

仍有少数超过 16.67ms 的帧，不保证所有显卡和文档恒定 60/120fps。禁用更新的排查使用 process_mode，因为仅 set_process(false) 会被下一次视图信号重新启用。

group_border_navigation_smoke 修改前因纹理生成、主题频繁失效失败，修改后通过；覆盖布局不变、相邻缩放缓存、填充像素、离屏恢复和样式修改。minimum_screen_border_smoke、navigation_cache_smoke、loading_title_style_smoke、hidpi_stage_smoke 通过。实际窗口填充截图已检查；缩放基准验证文件哈希、节点位置、布局版本不变。

手动验证：重启修改后的程序，打开大项目，连续快速缩小到全图再放大，拖动到另一片区域再缩放；应减少停顿，圆角、填充、文字、连线端点应保持正常。失败时重点检查圆角闪烁、填充消失、离屏返回后边框未更新或对象发生位移。用户桌面会话、发行包手动验收尚未执行。
