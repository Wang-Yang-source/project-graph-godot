# 缩放期间复用连线世界几何

## 原因与改动

源码检查发现，LineEdge._process 原先按当前缩放倍率计算 render_segments，并将其放入 _geometry_key。实际倍率大于 1 时，连续放大和缩小会改变采样点数，重新计算连接曲线、Curve2D 命名路径和 ConcavePolygonShape2D 碰撞线段。碰撞更新还调用 invalidate_geometry，推进舞台布局版本，导致依赖布局的预览和连线缓存继续失效。

改为按相机配置的最大缩放倍率选择采样精度，整个支持的缩放范围复用同一世界曲线。缩放仍更新原有 Line2D 屏幕宽度、抗锯齿与箭头显示缓存；端点位置、曲线精度、样式或最大倍率配置改变时，仍会重建世界几何。代价是低倍率下使用较多曲线点，点数保留既有 512 上限。没有降低最大支持倍率下的采样精度。

优先复用项目现有 LineEdge 曲线生成、Curve2D 缓存、Godot Line2D、ConcavePolygonShape2D 和原生数学功能，不引入依赖，也不另写通用渲染或曲线库。这个修改消除一条可由源码确认的重复计算路径，尚未证明它是用户当前低帧率的唯一原因。

## 实际改动与工具

- 仅修改 src/stage_object/association/line_edge/line_edge.gd 中采样精度的输入，新增本说明。
- 使用 mcp__godot_mcp__read_script 读取代码，mcp__godot_mcp__modify_script 修改脚本；编辑器脚本工具读取 Git 基线、暂存本次独立差异，保留工作区已有反向连线等未提交改动。
- 没有启动项目，没有运行测试、构建、格式检查或性能基准；没有测得修复后的 FPS，也未发布或更新安装包。

## 用户手动验证（尚未执行）

1. 用修改后源码运行程序，打开带较多连线的教程或结构化思维总图，启用“窗口 → 切换调试信息展示”。通过捏合或 Ctrl+滚轮在 50%–150% 显示倍率之间反复往返，覆盖实际倍率 1.0–3.0。应看到缩放连续，连线、箭头和文字保持位置；记录 FPS 和仍出现停顿的倍率。若依旧慢，重点区分全图绘制、首次字体生成、预览切换与后台负载。
2. 缩放到全图后重新放大，点击线段、箭头和关系文字。应仍能命中对应对象，端点不跳动。失败时重点检查视觉曲线与碰撞路径是否偏离，反向边和箭头是否错端。
3. 拖动一个有多条连线的节点，并编辑连线文字、线宽和曲线精度。应立即更新形状、碰撞与文字位置，撤销/重做可恢复。失败时重点检查停止缩放后的缓存是否没有随真实编辑失效。
4. 另存副本并重新打开，检查文本、位置与关系保留。已有安装版必须更新到本次源码构建才包含修复。

授权运行时，可复用现有 zoom_frame_benchmark、navigation_cache_smoke、edge_caption_smoke、connection_continuity_smoke、proportional_connections_smoke 和 reciprocal_connections_smoke；应额外比较纯缩放前后的舞台 layout_revision、连线 geometry_version 与碰撞线段，确认没有由倍率变化触发世界几何更新。
