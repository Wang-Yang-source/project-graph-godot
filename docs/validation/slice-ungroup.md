# 切割分组只解除分组

切线命中分组框时，仅删除该分组外壳，将直接成员提升到上层分组；保留成员位置、文字、内部连线及连线注释。即使同一切线同时穿过成员，也优先解除外层分组并保护其内容。嵌套子分组保留。菜单删除仍使用原来的级联删除；只切成员时仍删除该成员和关联线。

复用现有容器属性、删除流程与事务历史，没有新增依赖。通过 Godot MCP 脚本读取、创建、修改和编辑器脚本执行工具完成。

slice_ungroup_smoke 修改前无法保留内容，修改后通过，覆盖嵌套分组、成员及连线内容、位置不变、单步撤销与重做。slice_group_smoke 通过，验证单独切成员的原行为。

尚未执行的手动验证：对包含两个节点及一条带文字连线的分组框执行切割；框应解除，内部内容应保持原位。让同一切线穿过框和成员，再撤销、重做；成员不应误删、漂移或丢失连线。若失败，重点检查嵌套分组、同时命中成员及撤销后的容器关系。
