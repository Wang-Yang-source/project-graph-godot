# 拖动目标去重

同一指针位置会被输入事件和追赶的物理帧重复读取。保留指针速度采样，以实际目标和轴锁状态判断是否需要再次更新分组成员；每次按下开始新手势时重置缓存。复用 Godot 的 Vector3 值比较，无新增依赖。

通过 Godot MCP 的脚本读取、修改、创建及编辑器脚本执行工具完成。没有读取场景文本，也没有操作编辑器界面。提交只包含目标去重；工作区原有的非物理拖动、Shift 轴锁等修改保留在工作区。

Godot 4.8 dev6、Intel Iris Xe、Vulkan Mobile、关闭 VSync、1996×1248、UI 200%，同一教程文件快照有 975 个对象。各拖动采样 3 秒：未优化的复测为 9.93 FPS / P95 110.46 ms；仅目标去重为 17.07 FPS / P95 64.68 ms。独立调试进程数据，不代表 release 性能。原始文件哈希不变。

已通过 `drag_target_dedup_smoke.gd`、`master_mouse_smoke.gd`、`master_position_layout_smoke.gd`，并运行真实指针分组拖动基准。首次位置、静止位置、移动、轴锁切换与新手势重置均有检查。现有 `nonphysical_stage_smoke.gd` 在查询 direct_space_state 时失败（空间不可访问），headless 和图形进程均复现，未修改该测试。

手动复查：打开教程，拖动“伸缩链”分组，停住指针，再继续拖动；按住和松开 Shift，最后释放鼠标并撤销。预期成员同步移动、停住时稳定、轴锁响应及时、一次拖动只产生一次撤销。失败时重点检查停住后抖动、继续移动失效、第二次拖动失效、轴锁或抛掷速度异常。尚未由用户执行这组手动步骤，尚未取得 release 前后数据。
