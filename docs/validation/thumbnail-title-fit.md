# 缩略图标题比例验证

## 改动

- 复用 Godot 原生 Label 最小尺寸测量，保留原文字换行。
- 普通节点沿用世界坐标边界，不扩大为固定屏幕尺寸。
- 分组标题仅在顶部标题条内适配；所有标题均按可用宽高限制字号。
- 字号上限考虑整个缩放采样桶，避免连续缩放时超过 24 个物理像素。
- 低于 5 个物理像素的文字隐藏；不会改动保存的节点位置、大小或包含关系。

通过 Godot MCP 脚本读写和编辑器脚本执行工具运行 Godot 4.8 dev6：

- `thumbnail_title_fit_smoke.gd`：PASS。覆盖小节点不扩张、多行文字、标题边界、标题条高度、物理字号上限、序列化不变。
- `hierarchy_readability_smoke.gd`：PASS。覆盖层级切换、子标题和缩放后恢复。
- 使用教程文档副本生成 `/tmp/pg-thumbnail-fixed.png`，人工检查缩略视图。
- 没有引入依赖；复用原生 Label、Rect2 和现有概览节点。

## 用户手动验证（尚未执行）

1. 重新运行项目，打开教程文档，定位“手动调整树形布局”和“特性：伸缩链的间距”。
2. 连续缩小再放大。应看到边框与节点位置维持原布局，标题位于分组顶部；数字不应突然放大到遮挡相邻内容，多行说明不应合并成长行。
3. 极小倍率下文字可隐藏；重新放大后应恢复内容、颜色和连线。检查标题是否仍越过边框、重叠或在放大后缺失。
4. 编辑标题后再缩小，确认预览内容更新；撤销后应恢复原文字。

本次验证不证明拖拽帧率问题已完全解决，也不解决极大倍率下位图字体模糊。
