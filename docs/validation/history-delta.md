# 历史记录差量存储

历史条目保存变化对象的前后记录、对象顺序和顶层元数据，不再为每条操作保存两份完整对象记录。捕获与恢复仍使用现有快照适配；这一步尚未实现按需视图或完全由文档模型驱动的历史。

使用 Godot Dictionary/Array 的原生比较和复制，无新增依赖。`history_delta_smoke.gd` 已通过：1000 对象单对象编辑、撤销重做、创建删除与重排、元数据、过期基线拒绝和记录隔离。`document_load_transaction_smoke.gd` 和 `native_dirty_smoke.gd` 的断言通过；后者仍打印既有 feedback_tween 元数据错误。

原始 975 对象教程完整撤销快照仍有坐标差异（约 4.23 世界单位）；恢复旧 History 后相同失败，因此尚未通过整体回归。基础交互测试的设置页数量和文本换行断言修改前后都失败。不能用差量单元用例代替这些未通过的集成验收。

Godot 文件通过 MCP 脚本读取、创建、修改及编辑器脚本执行处理。手动验证：连续编辑两个节点，创建节点并连线，删除节点，然后逐次撤销和重做。应按一次用户操作恢复文字、对象顺序和连接，并保持未改动节点；失败时重点检查坐标漂移、断开的引用、撤销栈锁死和取消编辑误消耗历史。原教程坐标漂移与发布版内存实测尚待完成。
