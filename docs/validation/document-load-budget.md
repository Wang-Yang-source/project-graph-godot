# 文档加载优化与 2 秒验收

## 基线（2026-10-04）

复用 Godot 4.8.dev6 的 WorkerThreadPool、字体预渲染、PackedScene、原生容器和 ZIP/JSON；不增加运行时依赖。全部 Godot 文件通过 Godot MCP 脚本读写和编辑器脚本执行类别处理，场景只使用 PackedScene/ResourceSaver，不读取场景文本。

`tests/document_load_release_benchmark.gd` 是发布版计时入口。用 PackedScene 打包为独立验证场景再导出；环境变量 `PG_LOAD_DOCUMENT` 指向只读文件，`PG_MAX_LOAD_MS` 可设置性能门槛。桌面进程须传 `-- --new-window`，避免单实例转发导致计时程序退出。结果写入 `/tmp/pg-load-release-result.json`。

原始工作区发布版，Intel Iris Xe（Mesa OpenGL Compatibility），1280×800，新进程首次打开 `tutorial-main-3.1.prg`，975 对象：完整加载及绘制 20323.288 ms，加载帧 P95 64.888 ms，峰值 275.127 ms。阶段墙钟：后台准备 4579.972 ms、创建 15142.016 ms、历史捕获 216.094 ms；阶段包含调度等待，不能当作函数独占 CPU 时间。完整数量、连线引用、干净状态和源文件哈希通过。磁盘缓存未清空。

## 验收标准

全部持久对象、引用、碰撞、撤销基线就绪且首个可编辑画面绘制完成，P95 争取 ≤2000 ms；缩略图和离屏渲染可以随后准备。应用进程启动另计。首次导入、首次打开、再次打开分别记录，不把缓存命中等同于首次性能。
