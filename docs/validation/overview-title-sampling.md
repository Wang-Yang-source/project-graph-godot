# 缩小预览标题采样

预览标题使用大字号字形再缩小显示，但此前未启用 mipmap 纹理过滤。现在标题显式使用 Godot 的 LINEAR_WITH_MIPMAPS，与已有字形 mipmap 缓存配合，降低缩小时的笔画锯齿和闪烁。未增加字形缓存尺寸或额外依赖。

通过 Godot MCP 读写脚本及运行窗口测试。overview_sampling_smoke 修改前失败、修改后通过：真实容器在 0.04 倍缩放显示预览，并检查字体 mipmap 与标题过滤。只提交采样这一行，保留工作区已有预览逻辑改动。

手动验证：打开包含容器的大项目，慢慢缩小再放大，预览标题笔画应平滑且稳定。失败时重点观察文字碎点、闪烁或缺笔画。缩小到几个像素的完整中文句子无法保持可读，需要放大浏览；用户桌面与发行包的手动验收尚未执行。
