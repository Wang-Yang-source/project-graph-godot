# 圆角框选框

鼠标框选框复用现有 continuous_corners 的 NODE 连续圆角轮廓，与普通节点使用相同半径；较小框选区域自动限制半径。保留现有 Line2D、抗锯齿纹理、颜色和矩形选择判定。没有新增依赖。

使用 Godot MCP 脚本读取、修改和编辑器脚本执行工具。已通过 marquee_pixels_smoke（7 个缩放等级 × 4 个像素偏移，覆盖轮廓、边界、边缘可见性和取消清理）。像素测试坐标换算已适配原生高分辨率视口，并使用支持鼠标定位的 X11 驱动。另运行 click_selection_smoke，修改前后均存在同样的 11 项失败，未计为通过；此次仅修改框选轮廓，未修改选择判定。

尚未执行的手动验证：启动修改后的项目，在空白舞台按住鼠标左键拖出框选框；四角应与节点同款圆润，缩放及反向拖动后边框保持完整，松开后正常选择。若异常，重点检查小框四角、缩小后的边缘缺失和框选结果。
