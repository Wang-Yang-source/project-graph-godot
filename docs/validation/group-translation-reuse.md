# 分组整体平移复用

纯平移只改变世界坐标，保留局部形状；结构变化与几何变化分别递增版本。分组的成员关系不随拖动改变，布局应比较成员相对分组的姿态，而不是绝对世界坐标。内部连线两端等量平移时复用曲线、碰撞线段和标题路径，跨组连线仍重新计算。概览图比较根分组内的相对内容，整体平移移动展示节点，真实内容变化才重新生成纹理。

复用 Godot 的 Transform2D、Geometry2D、Shape2D、节点变换与现有缓存，不增加依赖。没有引入第三方空间索引或物理替代库：本次问题是项目将位置变化当成结构/局部形状变化，通用库不能修复这些失效规则。保留世界坐标、原有外部碰撞和事务式历史；分组移动期间由根刚体驱动后代的固定偏移，折叠隐藏的成员从原生物理空间移除，展开时恢复。

脚本操作使用 Godot MCP 的脚本读取、修改、创建，以及编辑器脚本解析和启动测试类别；不修改第三方插件。

分组显示名称/预览后，内部元素应禁止单独拖动或作为多选移动的独立驱动；整体移动只通过可见分组进行，内部保持固定偏移。手动拖动分组靠近外部文本块。预期只出现分组整体与外部对象的碰撞，隐藏成员不得把预览内部挤散；放大展开后，单个成员仍可移动、拾取和参与正常碰撞。来回缩放切换，取消拖动、撤销、重新打开副本，检查内部成员相对位置、内部/外部连线和碰撞状态恢复。若内部乱动、整组穿过外部对象或展开后无法碰撞，应视为失败。自动逻辑验证已覆盖这些状态，用户视觉验收尚未执行。
