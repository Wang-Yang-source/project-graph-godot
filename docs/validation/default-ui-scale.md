# 默认界面缩放

设置中的界面缩放默认值从 100% 调整为 200%，改善默认界面文字、图标和控件过小的问题。默认值在 `GraphPreferences.DEFAULTS` 中定义，既有 `_apply_ui_scale()` 使用该值设置窗口的 `content_scale_factor`，设置面板也读取同一来源。

已保存的用户缩放选择继续优先于默认值。已有配置若保存了 100%，需要在设置中改为 200%；本次不改写个人配置。

复用 Godot 内置 ConfigFile 和 Window 缩放能力，以及现有偏好设置和原生像素舞台渲染路径；无需新增社区库或依赖。

项目文件通过 Godot MCP 的脚本读取、修改工具处理。依照仓库运行授权规则，尚未执行测试、构建、格式检查或界面验证。

## 手动验证（待执行）

1. 在没有保存 `ui_scale` 设置的独立用户环境启动程序，打开设置。界面缩放应显示 200%，文字、图标及按钮应与手动选择 200% 时一致。
2. 切换到 100%，再切换回 200%，打开菜单、设置和保存对话框。各区域应同步调整，文字和按钮不应重叠或被裁切，画布点击应命中鼠标所在位置。
3. 保存任意界面缩放选择并重新启动。应保留已保存的选择。
4. 在小屏幕和高 DPI 屏幕分别检查窗口与弹窗。若默认仍显示 100%，先检查是否存在已保存的 `ui_scale`；若出现裁切、重复放大或点击偏移，重点检查窗口最小尺寸、系统 DPI 和舞台输入坐标换算。
