# 欢迎页与舞台互斥

欢迎页原先只显示卡片，舞台、标签页和边缘工具栏仍可见，空白边缘也可能把鼠标输入转发给舞台。现在通过欢迎页的 visibility_changed 信号同步隐藏舞台标签容器、禁用边缘工具栏并隐藏舞台状态；关闭欢迎页恢复原文档，并保留课堂模式等偏好。打开欢迎页时结束舞台编辑和交互、释放文本焦点，阻止舞台快捷键及文本转发。欢迎卡片的可用区域从主界面页头下方开始，避免遮挡页头。

复用 Godot 内置 Control 可见性、信号、SubViewportContainer 输入转发规则及现有 DockAutoHide；不需要通用算法或第三方库，不增加依赖。脚本读取、修改、测试脚本创建与 Godot 运行均通过 mcp__godot_mcp__ 工具；未直接读取或写入场景文本，未改动场景和外部插件。普通验证文档使用文本工具。

自动回归：tests/welcome_stage_smoke.gd。先复现启动时欢迎页与舞台同时可见，修复后无界面及 Compatibility 渲染模式均返回 WELCOME_STAGE: PASS。覆盖启动互斥、页头边界、边缘双击、舞台删除快捷键隔离、偏好刷新、Esc 返回、主页重开、保留文档、首页显示期间新增标签、新建草稿及课堂模式。渲染模式额外覆盖亮暗主题、1152×648 与 800×600 的逻辑布局，截图无舞台叠加且卡片不覆盖页头、不超出内容区域。窗口管理器固定实际窗口为 1920×1200，因此尺寸用根界面的 Control 布局模拟；未验证真实窗口缩放操作。脚本解析与 git diff --cached --check 通过。测试在现有工作区上执行，本次提交只包含修复相关改动，保留此前未提交的文件库和预览工作。

用户手动验证（尚未执行）：

1. 启动应用或点击顶部主页入口。应看到欢迎卡片，舞台内容、标签页、状态栏及边缘工具栏不应叠加显示；将鼠标移到右侧或底部，工具栏不应出现。重点检查边缘是否露出舞台或接受双击创建节点。
2. 在已有文档中打开主页，按 Delete、撤销快捷键及点击卡片外侧，再按 Esc 或点击欢迎页关闭按钮。原舞台应恢复，文档内容不变，编辑和拖拽不应继续卡住。重点检查快捷键是否穿透及关闭后舞台是否仍隐藏。
3. 从欢迎页新建草稿或打开最近文件。应隐藏欢迎页并进入对应舞台；关闭最后一个空白草稿应重新显示欢迎页。重点检查是否再次出现两层内容。
4. 分别在亮暗主题缩小真实窗口。欢迎页应位于页头下方，关闭按钮与搜索保持可用。重点检查顶部遮挡、底部溢出及关闭后的工具栏偏好恢复。
