# 缩小后的预览布局

修复无标题分组折叠成大空框、嵌套预览最小高度突破父框尺寸上限，以及按 em 大小拟合中文标题导致实际行高溢出的问题。无标题分组保留细节；有标题预览按原生字体实际行高拟合；嵌套预览遵守父框尺寸限制；遮住根标题或前一个子预览的次级预览暂时省略。显示缓存在矩形或标题改变后更新，放大后恢复原始内容。预览的线宽、圆角和上限按视口实际像素换算，预览边框改为一个像素。

复用 Godot 原生字体度量、Rect2、Panel/Label、现有预览池和 mipmap，无新依赖。通过 Godot MCP 读写脚本、执行测试和读取原生资源；未直接读写场景文件。仅提交本次预览修改，保留已有工作区改动。

thumbnail_layout_smoke 修改前出现三个对应失败，修改后通过，覆盖空标题、文字边界、父子尺寸、标题遮挡、200% 像素线宽、原地增删标题、缩放往返和保存数据不变。overview_sampling_smoke 通过，窗口截图已检查。两个工作区已有测试 rounded_compact_preview_smoke/next_layer_preview_smoke 在本次修改前后均因预览触发条件与夹具不符而访问不存在的预览并超时；保留原测试，未宣称全部通过。

同一 1028 对象缩放基准在完整修改后通过，校验源文件哈希、对象位置和布局版本不变：局部 P95 7.701ms，大范围首次/重复 P95 21.176/21.603ms；最大帧分别 25.751/45.806/38.253ms。仍存在少数慢帧。

手动验证：重启修改后的程序，打开原教程，逐步缩小到两张截图的倍率。应避免放大的空框，标题应留在框内，次级标题不遮住根标题；放大后全部节点和连线恢复，保存、撤销的布局保持不变。失败时重点检查空框、重叠标题、残影和放大后未恢复的对象。用户实际桌面和发行包手动验收尚未执行。
