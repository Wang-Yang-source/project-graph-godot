# 完整文档模型第一阶段

新增 GraphDocument：保存原生持久记录与独立资产映射，维护对象、容器成员、主题子节点、端点关联边、集合成员反向索引。输入与查询结果隔离；before/after 事务先校验整个候选，再同时替换正文与索引。重复 ID、悬空引用、过期事务和运行时资产值不进入模型。复用项目 PRG v4 校验/快照适配及 Godot Dictionary/PackedStringArray，不增加通用数据库或第三方依赖。

Stage 保存与 History 捕获接入 document_snapshot。当前过渡阶段仍保留所有活动节点，发生持久 revision 变化时从节点同步完整模型；同一 revision 的重复捕获复用模型。这一阶段尚未改为记录差分历史，也没有按需节点、局部物理、完整数据命中或模型驱动的全选/分组/导出。不能将本阶段称为整个架构已完成，也不声明首开提速。

通过：纯数据模型原子事务、无节点创建/编辑/逆事务、输入别名隔离、悬空删除拒绝、过期事务拒绝及完整快照往返；native_dirty_smoke、加载事务、975 对象主教程增量撤销（保留全部 975 实例，51.079 ms），625 对象旧 master 图文导入/撤销/保存重开。Godot 运行时解析通过。GUI 手动检查和模型驱动的视图回收尚未执行。

Godot MCP 类别：脚本读取/创建/修改与编辑器脚本执行。提交仅含模型与对应接入，不包含原工作区其他改动。没有读取场景文本或修改第三方目录。

用户手动验证：打开主教程，编辑文字、移动节点、撤销/重做，保存后重开；全部对象、图片、分组与连线应保留，未编辑时应干净。失败时重点检查模型同步错误、ID 冲突、引用断开、撤销后脏状态及保存丢对象。完整按需视图接入后还需验证永未显示对象、跨视口连线、离屏分组移动和回收后的撤销。
