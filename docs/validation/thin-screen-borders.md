# 缩小后的细边框

场景中的补偿边框原本为 3 个逻辑像素，而且坐标换算未包含视口的最终像素缩放。200% 时测试测得边框核心宽度约 6.03–6.22 个实际像素。现在脚本将补偿线宽设为 1，并使用视口最终变换计算轮廓、可见区域和缩放档位，核心宽度约 1.00–1.06 个实际像素。正常倍率仍沿用原有世界边框；视口尺寸改变后重新计算。

复用原生 Line2D 和矩阵变换，无新增依赖。通过 Godot MCP 修改脚本、实例化原生场景、运行窗口测试；不直接改写场景文件。

border_screen_width_smoke 修改前失败、修改后通过，覆盖 200% 渲染比例下 0.02/0.125/0.25/0.49 倍缩放与实际图像中的边框覆盖行数。minimum_screen_border_smoke、group_border_navigation_smoke、hidpi_stage_smoke 通过。已检查细边框窗口截图；物理和布局保持不变。

手动验证：重启修改后的程序，打开原项目，缩小到截图中的全图视图，再切换界面比例或调整窗口大小；边框应细且连续，不出现原来的粗灰色带。失败时重点检查是否运行旧程序、线宽是否随界面比例异常放大、细线是否消失。用户桌面会话和发行包手动验收尚未执行。
